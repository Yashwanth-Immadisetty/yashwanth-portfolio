Full Stack · Django · Python

Uday Mart — E-Commerce Platform

A complete village supermarket web application built from scratch. Features end-to-end shopping flow: catalog, cart, checkout, order tracking, wishlist, reviews, and a full-featured admin dashboard.

  • MVT architecture with 9 relational database models and full Django ORM
  • RESTful JSON API endpoints powering live cart (AJAX, no page reload)
  • Dual stock validation — at cart add and again at checkout
  • Immutable StockLog audit trail for every inventory movement
  • Signals-driven UserProfile auto-creation on registration
  • Context processor injecting cart count globally into all templates
  • Remember Me session management (30-day persistent sessions)
  • Custom Django Admin with image previews & color-coded status badges
